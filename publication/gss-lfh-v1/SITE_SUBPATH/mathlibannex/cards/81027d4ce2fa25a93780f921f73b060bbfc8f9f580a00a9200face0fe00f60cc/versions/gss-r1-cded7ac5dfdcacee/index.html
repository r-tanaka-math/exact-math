NormedSpace.geometricStructureClosure

def

The geometric structure closure

Statement

The geometric structure closure equips the set of geometric points with the hull–kernel rule. It closes a collection of points by intersecting them as subsets of the original vector space and then taking all geometric points containing that intersection.

Definition

Conclusion

The result is the closure space . A collection of geometric points is closed when it is fixed by the displayed operation. This operation acts on collections of points; it is distinct from norm closure inside .

The source separately proves (distinct points have distinct singleton closures) and later (every singleton is closed), the latter using incomparability of distinct geometric points under inclusion. Finite-union preservation is not asserted here. For the zero space, the carrier is empty and the same construction applies.
