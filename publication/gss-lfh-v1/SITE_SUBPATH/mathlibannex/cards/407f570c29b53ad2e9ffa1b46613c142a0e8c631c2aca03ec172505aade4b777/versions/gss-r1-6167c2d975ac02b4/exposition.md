# The intersection of a pure-state component is its GNS representation kernel

## Statement

Let $A\ne\{0\}$ be a complex C*-algebra, possibly without an identity. A state on $A$ is a positive bounded complex-linear functional of norm one. It is pure if it is an extreme point of the state space, regarded as a real convex set. Let $\varphi$ be a pure state. Let $(H_\varphi,\widetilde\pi_\varphi,\xi_\varphi)$ be the GNS model of its canonical state extension $\widetilde\varphi(\lambda,a)=\lambda+\varphi(a)$ to the forced unitization $\mathbb C\oplus A$, and let $\pi_\varphi=\widetilde\pi_\varphi|_A$.

By [the extreme-kernel theorem](https://exactmathematics.org/exact-mathematics/mathlibannex/sources/gss-v0.5.0/MathlibAnnex/Analysis/CStarAlgebra/GeometricStructure/ExtremeKernel.lean.html?from=21&start=49&end=65#L49), $S(A)$ is the family of kernels $\ker\rho\subseteq A$ of bounded complex-linear functionals $\rho:A\to\mathbb C$ that are extreme points, for real convexity, of the entire closed dual unit ball $B_{A^*}$, with closure $c_A(\mathcal T)=\{I\in S(A):\bigcap_{J\in\mathcal T}J\subseteq I\}$. The pure-state kernel $\ker\varphi$ is one such point, by the [pure-state extremality theorem](https://exactmathematics.org/exact-mathematics/mathlibannex/sources/gss-v0.5.0/MathlibAnnex/Analysis/CStarAlgebra/FacialStructure/PureStateExtreme.lean.html?from=21&start=29&end=76#L29). Let $C(\ker\varphi)$ denote its component for the finite-chain relation generated by equal points and nonclosed pairs. Write $\mathrm{GS}(A)$ for the set of these components. For a component $C$, put $J_C=\bigcap_{I\in C}I$, and write $\mathrm{PS}(A)$ for the family of all such intersections. The canonical map is

$$
\gamma:\mathrm{GS}(A)\longrightarrow\mathrm{PS}(A),\qquad \gamma(C)=J_C.
$$

Then, as subsets of the original algebra,

$$
\gamma(C(\ker\varphi))=J_{C(\ker\varphi)}=\ker\pi_\varphi.
\tag{1}
$$

On the left we display the underlying subset of the primitive geometric point.

## Assumptions

The given functional $\varphi\in A^*$ is positive, has norm one, and is extreme in the state space for real convexity; $A$ carries its compatible C*-order. The GNS action is formed from this very state's canonical extension. The representation is fixed by $\varphi$; faithfulness is not assumed.

## Conclusion

The whole component's intersection is the representation kernel $\ker\pi_\varphi$, using this fixed GNS representation. An individual functional kernel $\ker\varphi$ need not equal that intersection. Formula (1) is an equality of subsets; it gives neither injectivity of $\gamma$ nor a comparison of topologies by itself.

private def absoluteStateContinuousMap {H : Type v}
    [NormedAddCommGroup H] [InnerProductSpace ℂ H] [CompleteSpace H]
    (pi : NonUnitalCStarRepresentation A H) : A →L[ℂ] (H →L[ℂ] H) :=
  LinearMap.mkContinuous
    { toFun := pi, map_add' := map_add pi, map_smul' := map_smul pi }
