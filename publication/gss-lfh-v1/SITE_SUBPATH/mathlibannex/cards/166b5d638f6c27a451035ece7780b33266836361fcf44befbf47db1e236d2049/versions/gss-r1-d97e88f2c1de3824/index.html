Conclusion

One faithful pure-GNS representation and one inverse-image homeomorphism satisfy all three formulas. In (3), the same map is followed by . The conclusion identifies the normal parts under this composite; it does not identify a normal part with its entire geometric structure space.

Main citations

Faithful normal-part transport gives all the outputs for the same pure state and the same homeomorphism. The component-density criterion characterizes faithfulness of the pure-GNS representation. The forward preimage formula and inverse preimage formula concern the same range restriction; the normal-part image identity specifies which subset is transported.

    (hS : NonUnitalCStarRepresentation.IsIrreducible (NonUnitalStarSubalgebraClass.subtype S))
    (e : ClosureSpace.Homeomorph (NormedSpace.geometricStructureClosure ℂ S)
      (NormedSpace.geometricStructureClosure ℂ B)) :
    ∃ phi : NonUnitalPureState B, Function.Injective phi.gnsRepresentation ∧
      ∃ r : ClosureSpace.Homeomorph (NormedSpace.geometricStructureClosure ℂ (NonUnitalStarAlgHom.range phi.gnsRepresentation))
          (NormedSpace.geometricStructureClosure ℂ B),
        (∀ J, (r.toEquiv J).val = (NonUnitalStarAlgHom.rangeRestrict phi.gnsRepresentation) ⁻¹' J.val) ∧

        (e.trans r.symm).toEquiv '' normalPart S = normalPart (NonUnitalStarAlgHom.range phi.gnsRepresentation)
