ClosureSpace.IsLinkedSet

def

Defines subsets whose every pair of points is linked in the ambient closure space.

Statement

Let be a closure space and let . The linked-set predicate requires every two points of to be linked with respect to the ambient closure . It includes the empty set and singletons.

Definition

A set is closed when . The ambient linked relation is

Thus the linked-set condition is

Both points are chosen from the same set , while the closure of their pair is taken in the given ambient space . Distinct points must form a nonclosed two-point set. When the two points coincide, the equality alternative already makes them linked.

This is a direct pairwise condition. The separate relation of belonging to the same component is generated by finite chains of linked pairs. A chain may pass through intermediate points; it does not replace the pairwise test in this definition.

Assumptions

The inputs are the closure space and an arbitrary subset . Nonemptiness, two or more elements, closedness and maximality are not required. No finite-character or finite-union property is imposed on the closure.

Conclusion

The definition returns a proposition about all pairs in , with their membership conditions explicitly quantified. It neither chooses a distinguished point nor asserts that is a whole component or a maximal linked subset.

The cited empty-set and singleton lemmas are separate consequences, not extra clauses of the definition. For the empty set there is no to test. For , any two members both equal , so the equality alternative of the linked relation applies. These two arguments explain why the definition admits these cases without a nonemptiness convention.

/-- Equality or a nonclosed two-point set. -/
def Linked (c : ClosureSpace α) (x y : α) : Prop := x = y ∨ ¬ c.IsClosed {x, y}

theorem linked_refl (c : ClosureSpace α) (x : α) : c.Linked x x := Or.inl rfl

Source LinkedSet.lean, lines 34–41:

theorem isLinkedSet_empty (c : ClosureSpace α) : c.IsLinkedSet ∅ := by
  intro x hx
  exact hx.elim

/-- Reflexivity of `Linked` makes every singleton an R-set. -/
theorem isLinkedSet_singleton (c : ClosureSpace α) (x : α) : c.IsLinkedSet {x} := by
  rintro y rfl z rfl
  exact c.linked_refl _

Source Basic.lean, lines 60–61:

theorem isClosed_iff (c : ClosureSpace α) (s : Set α) :
    c.IsClosed s ↔ c.closure s = s := c.toClosureOperator.isClosed_iff

/-- The equivalence relation generated by linked pairs. -/
def componentSetoid (c : ClosureSpace α) : Setoid α := Relation.EqvGen.setoid c.Linked

/-- Belonging to the same finite-chain component. -/
abbrev Related (c : ClosureSpace α) (x y : α) : Prop := (c.componentSetoid).r x y

def component (c : ClosureSpace α) (x : α) : Set α := {y | c.Related x y}
