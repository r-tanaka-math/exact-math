Closure spaces before topology

Statement

A closure space is a set with an extensive, monotone and idempotent operation on its subsets that sends the empty set to the empty set. Preservation of finite unions is a separate condition.

Assumptions

The underlying set is arbitrary and may be empty. To specify a closure space, one supplies the map and the four displayed properties. No topology, metric or separation condition on is required.

  /-- An element is less than or equal its closure -/
  le_closure' : ∀ x, x ≤ toFun x
  /-- Closures are idempotent -/
  idempotent' : ∀ x, toFun (toFun x) = toFun x
