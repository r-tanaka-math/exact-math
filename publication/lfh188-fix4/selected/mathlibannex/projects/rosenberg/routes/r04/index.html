Scope

One represented rank-one projection yields every rank-one operator using dense orbits. Closed-range and compact approximation arguments put all compact operators in the image of the original algebra.

3 direct Cards + 16 reused prerequisites = 19 unique Cards. This count is a selected Card closure, not a source-declaration count.
