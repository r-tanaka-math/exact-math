5/-!
6# A separable faithful representation of the same shell-family target
7
8The state is extended onto the existing concrete algebra before any new
9representation is introduced. Its ordinary GNS representation is then proved
10separable, and the already established closed-ideal dichotomy proves it
11faithful. No irreducibility of this representation is assumed.
12-/
