141/-- Actual completed-CAR source data produces a faithful irreducible concrete
142atomic model.  All projection flags, support identities, and rank-one limiting

145difference shell and on the rank-one limiting defect. -/

153      (∀ i, L i (MathlibAnnex.CStarAlgebra.PureState.selectedEmbedding completedRootPureState i
