Conclusion

The coefficient counts the number of row replacements. The norm is specifically the sup operator norm; the estimate is not being asserted here with an unspecified norm on the same coordinate space.

The row estimate uses the sum of the absolute values of entries, not the Euclidean length of a row. This fits the sup norm through a sign vector. All coordinate matrices refer to the standard coordinate basis, so their determinants are the determinants of the original linear maps.
