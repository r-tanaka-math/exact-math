Lean realization notes

This is a fixed choice, not a uniqueness theorem for all possible families. In particular, the non-root links need not be unique. The subsequent structural theorem uses this very family. The present definition does not itself prove uniqueness of the irreducible representation class, the rank-one identities, simplicity, or the exclusion of compact-operator algebras.
