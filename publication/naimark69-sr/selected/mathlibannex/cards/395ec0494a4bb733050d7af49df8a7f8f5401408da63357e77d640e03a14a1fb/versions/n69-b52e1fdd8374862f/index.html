Definition

The first requirement transports the state exactly, with the stated composition direction. The second is point-norm approximate innerness: a finite amount of algebra data can be moved almost as moves it. Both requirements concern the same . No continuous path of unitaries is part of this definition.

Lean realization notes

This declaration defines a property; the separate CAR homogeneity theorem proves it. It does not assert that itself is inner or that implementing unitaries converge. The proposition about all simple separable unital C*-algebras named Kishimoto–Ozawa–Sakai is a different, more broadly quantified source definition.
