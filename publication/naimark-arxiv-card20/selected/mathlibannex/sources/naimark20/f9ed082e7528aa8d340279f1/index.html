152/-- The same fixed algebra has a faithful representation on a nontrivial separable
153Hilbert space, but has no nonzero irreducible representation on any separable

155the algebra is nonprimitive: the original irreducible model is retained. -/

157    AtomicCounterexampleEndpoint.{v} ∧
158    Nontrivial SeparableCounterexampleHilbertSpace ∧
159    TopologicalSpace.SeparableSpace SeparableCounterexampleHilbertSpace ∧
160    (∃ ρ : Representation AtomicCounterexampleAlgebra SeparableCounterexampleHilbertSpace,
